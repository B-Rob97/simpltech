# SimplTech

Company site for **SimplTech Inc.** — web development for startups and small to medium-sized businesses.

**Domain:** [simpltech.ca](https://simpltech.ca)

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Motion (`motion` / Framer Motion)
- SEO: metadata, Open Graph image, `sitemap.xml`, `robots.txt`, JSON-LD

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
